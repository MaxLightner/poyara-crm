# پویارا CRM 0.20.0 — Agent سبک خودکار با Cloudflare Workers AI

## تصمیم فنی

- **LLM**: `@cf/zai-org/glm-4.7-flash` (مدل چندزبانه Workers AI).
- **گفتار زنده**: SpeechRecognizer خود Android / Google، بسته به سرویس انتخابی گوشی؛ ممکن است شبکه بخواهد.
- **فایل صوتی ضبط‌شده**: مسیر اختیاری `@cf/openai/whisper` برای رونویسی M4A و سپس GLM برای تولید دستورات. پشتیبانی عملی این قالب و دقت گفتار فارسی روی گوشی باید تست شود.
- **CRM موتور اجرا**: Kotlin + SQLite؛ پاسخ هوش مصنوعی فقط JSON با دستورهای شناخته‌شده، نه دسترسی مستقیم به SQL یا تلفن.
- **مسیر بدون اینترنت**: کادر و پیش‌نویس‌ها، شماره‌ها و اجرای قواعد ساده محلی فعالند. Agent ابری بدون اینترنت کار نمی‌کند.
- **جریان خودکار**: پایان ویس → درج متن در کادر → تحلیل Agent یک بار → ثبت/اصلاح داده‌های معتبر و قرار → اعلان وضعیت. در خطا متن باقی می‌ماند و گزینه تلاش مجدد نمایش داده می‌شود.

## هزینه و سیاست منطقه‌ای

در طرح رایگان Cloudflare Workers AI، سهمیه روزانه ۱۰٬۰۰۰ Neurons است؛ تعداد معادل ویس ثابت نیست.
سهمیه و وضعیت سرویس می‌توانند تغییر کنند، و استفاده بالاتر به طرح Paid نیاز دارد. طبق یک بررسی
مستقل در تابستان ۱۴۰۵، دسترسی مستقیم از ایران در آن زمان موفق بوده است؛ این گزارش تضمین
دسترسی فعلی، پشتیبانی رسمی کشور یا امکان ساخت حساب نیست. در منطقه کاربر و با حساب خودش تست شود.

**ChatGPT Free هیچ API دائمی رایگانی برای اتوماسیون پویارا نمی‌دهد.**
حساب ChatGPT و API OpenAI مجزاست.

## راه‌اندازی یک‌باره

۱. حساب رسمی Cloudflare بسازید و Workers AI را در داشبورد فعال کنید.
۲. مقدار ۳۲ کاراکتری Account ID را از داشبورد دریافت کنید.
۳. در بخش API Tokens، توکن محدود با مجوز اجرای Workers AI ایجاد کنید؛ کلیدهای Global API را به اشتراک نگذارید.
۴. در پویارا ← تنظیمات ← هوش مصنوعی، رضایت ارسال متن/صوت را تأیید و Account ID و API Token را ذخیره کنید.
۵. با یک جمله ساده «آقای حسینی، شماره صفر نه یک پنج ...» اتصال و ثبت خودکار را روی گوشی تست کنید.
۶. اگر خطای 401/403 رخ داد دسترسی توکن یا محدودیت حساب و منطقه را بررسی کنید؛ خطای 429 یعنی سهمیه/ظرفیت پایان یافته است.

در این نمونه، API Token به‌صورت رمزنگاری‌شده با Android Keystore در دستگاه ذخیره می‌شود.
برای استفاده چند نفر بهتر است یک Cloudflare Worker مرکزی با احراز هویت جداگانه بسازیم تا
توکن مدیریتی فقط روی سرور بماند؛ اشتراک یک توکن بین دستگاه‌ها توصیه نمی‌شود.

## آزمون‌های پذیرش

- ضبط زنده → درج متن اولیه → تحلیل خودکار بدون دکمه پردازش
- نام آقای حسینی و دو شماره معتبر → یک شماره اصلی + یک شماره اضافی
- اشتباه‌گفتن نام خانوادگی و اصلاح لفظی → اصلاح رکورد همان فرد
- «فردا ساعت سه عصر جلسه» → قرار آینده و اعلان مناسب، بررسی در برنامه کاری
- «ساعت سه جلسه» بدون روز → تأیید یا سؤال؛ بدون ثبت زمان ساختگی
- اینترنت قطع → حفظ پیش‌نویس و امکان تلاش دوباره
- فیلتر «مدیریت» → مدیرعامل و مدیر فروش، بدون شلوغ‌کردن فهرست مخاطبین
- مخاطبین → فقط نام و شماره؛ جست‌وجوی متن توضیح، سمت و گروه همچنان فعال
- اتصال Google Contacts فقط در تنظیمات؛ نه در لیست مخاطبین

**وضعیت:** کد و CI صحت ساخت را بررسی می‌کنند؛ ورود حساب Cloudflare، دسترسی ایران،
خروجی واقعی مدل، کیفیت رونویسی Whisper و اعلان روی گوشی هنوز نیاز به تست عملی دارند.
