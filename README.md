# POYARA CRM — پویارا

## نسخه 0.21.0 — Agent مرکزی پویارا

- **یک Agent مشترک برای تمام گوشی‌های تیم:** Cloudflare Workers AI از طریق Worker مرکزی؛ هیچ کاربری Account ID یا API Token وارد نمی‌کند.
- **پردازش خودکار پس از ضبط:** متن فارسی یا فایل صوتی حداکثر ۴ مگابایت به Worker فرستاده می‌شود و دستورهای مجاز CRM در گوشی اعتبارسنجی و اعمال می‌شوند.
- **مدل‌ها:** `@cf/zai-org/glm-4.7-flash` برای متن، `@cf/openai/whisper` برای رونویسی اختیاری صوت.
- **محافظت از حساب:** توکن اصلی Cloudflare فقط در GitHub Secret بخش استقرار است؛ Worker با رمز اپِ مستقل و محدودسازی درخواست، دسترسی را کنترل می‌کند. رمز مشترک داخل APK آزمایشی قابل استخراج است و جایگزین احراز هویت تولیدی نیست.
- **انتشار:** Workflow بعد از اتصال Secret مدیریتی به GitHub، Worker را منتشر می‌کند و یک APK متصل به آدرس واقعی آن در GitHub Releases قرار می‌دهد.
- **وضعیت انتشار:** تا قبل از ثبت Secrets و اجرای موفق Workflow، بک‌اند مرکزی آنلاین و APK دارای اتصال واقعی **آماده نیستند**. ساخت معمولی CI صرفاً صحت کد را نشان می‌دهد.
- مخاطبین همچنان محلی هستند؛ داشتن Agent مشترک به معنی همگام‌سازی خودکار همه داده‌های CRM نیست.
- [راهنمای یک‌باره راه‌اندازی مالک حساب](docs/poyara-central-cloudflare-setup-fa.md)

## نسخه 0.20.0 آزمایشی — Agent خودکار با Workers AI

- سرویس پیش‌فرض **Cloudflare Workers AI** با مدل چندزبانه `@cf/zai-org/glm-4.7-flash` برای استخراج فارسی و دستورهای CRM است؛ Gemini به‌طور پیش‌فرض صدا زده نمی‌شود.
- مسیر آزمایشی تبدیل فایل M4A به متن از `@cf/openai/whisper` استفاده می‌کند؛ مسیر سریع‌تر Google SpeechRecognizer زنده را حفظ کرده‌ایم.
- سهمیه Free طرح Workers AI روزانه **۱۰٬۰۰۰ Neurons** است و در صورت اتمام سهمیه، درخواست رد می‌شود؛ برخلاف یک سرویس رایگان نامحدود.
- باید یک حساب Cloudflare Workers AI و API Token مجاز به اجرای Workers AI، **یک بار در تنظیمات گوشی** وارد شود؛ اطلاعات روی گوشی با Android Keystore رمزنگاری می‌شوند. پویارا هنوز سرویس مرکزی برای تقسیم کلید بین اعضا ندارد.
- **پردازش خودکار بعد از ویس:** متن گفتار در کادر نوشته و سپس بدون لمس دکمه پردازش تحلیل می‌شود. فایل خام با حالت M4A در صورت فعال‌بودن Cloudflare از مسیر Whisper بررسی می‌شود.
- Agent می‌تواند اصلاح نام و شماره، افزودن چند شماره، سمت و گروه، یادداشت و قرار را در قالب دستورهای محدود اجرا کند؛ حذف و ابهام نیاز به تأیید دارند.
- فهرست مخاطبین فشرده و فقط شامل نام و شماره اصلی است؛ نام مجموعه، سمت، تگ‌ها و یادداشت‌ها فقط در پرونده یا جست‌وجو استفاده می‌شوند.
- اتصال Google Contacts فقط از قسمت تنظیمات انجام می‌شود. سمت‌ها ورودی آزاد با منوی سمت‌های پرکاربرد دارند و فیلتر مدیریت تمام عنوان‌های مدیر را می‌گیرد.
- **دسترسی از ایران تضمین نمی‌شود:** یک بررسی مستقل اتصال Cloudflare Workers AI را در تیر ۱۴۰۵ گزارش کرده اما راه‌اندازی حساب، قوانین منطقه‌ای و دسترسی شبکه باید روی گوشی و حساب واقعی بررسی شوند.
- ChatGPT رایگان API دائمی رایگان برای اپلیکیشن‌ها فراهم نمی‌کند.
- [راهنمای راه‌اندازی و آزمون](docs/poyara-020-cloudflare-free-agent-fa.md)

## نسخه آزمایشی 0.19.2 — رفع ضبط، پیش‌نویس و ناوبری

- «تنظیمات» یک تب مستقل در نوار پایین است و «پیامک» از نوار حذف شده؛ قابلیت پیامک در پرونده همچنان باقی است.
- دکمه قرمز به‌طور پیش‌فرض از تبدیل گفتار زنده استفاده می‌کند و متن بعد از توقف به کادر توضیحات اضافه می‌شود.
- از تنظیمات می‌توان به حالت ذخیره فایل M4A تغییر داد؛ خواندن فایل ضبط‌شده توسط SpeechRecognizer روی همه گوشی‌ها پشتیبانی نمی‌شود.
- اگر تبدیل فایل صوتی شکست بخورد، پیام وضعیت دیگر داخل کادر مشتری یا دفترچه مخاطبین ذخیره نمی‌شود؛ فایل صوتی محفوظ است.
- ساخت مخاطب جدید و نمایش در دفترچه منوط به تکمیل نام و شماره معتبر است. یادداشت و صوت ناقص در پیش‌نویس محلی می‌ماند.
- مخاطبین ناقص قدیمی پاک نمی‌شوند؛ از بخش «پیش‌نویس‌های نسخه‌های قبلی» در تنظیمات قابل بازکردن و تکمیل هستند.
- Agent از روی پرونده خالی هم می‌تواند اطلاعات استخراج کند؛ بعد از کامل‌شدن نام و شماره، پرونده واقعی ساخته می‌شود.
- همگام‌سازی Google Contacts رکوردهای ناقص را ارسال نمی‌کند.
- Google Contacts / Gmail به صورت خودکار کلید Gemini API نمی‌سازد. کلید فقط یک‌بار توسط دارنده پروژه در Google AI Studio یا به‌صورت مرکزی در یک سرور امن تنظیم می‌شود.
- Gemini API در فهرست مناطق رسمی در ایران قرار ندارد. اگر در منطقه پشتیبانی‌نشده باشید، اتصال رایگان قابل تضمین نیست؛ از راهکار دارای مجوز/در دسترس منطقه استفاده کنید.

## نسخه آزمایشی 0.19.0 — UI جدید و Agent رایگان Gemini

- مدل پیش‌فرض Agent متنی: **Google Gemini 3.5 Flash-Lite** (Free Tier در حساب‌های واجد شرایط).
- گفتار زنده با سرویس گفتار گوشی به متن تبدیل می‌شود؛ Gemini فقط متن را به دستور JSON CRM تبدیل می‌کند.
- برای مسیر رایگان `OPENAI_API_KEY` لازم نیست. کلید `GEMINI_API_KEY` فقط روی سرور HTTPS ذخیره می‌شود.
- کاربر باید صریحاً با ارسال متن گفتار مشتری به سرویس ابری موافقت کند؛ در Free Tier گوگل ممکن است داده‌ها را برای بهبود محصولات استفاده کند.
- فقط متن همان گفتار و نام/مجموعه پرونده فعلی ارسال می‌شود، نه تمام مخاطبین.
- ذخیره و پردازش محلی بدون Agent حفظ شده و خطای شبکه / سهمیه، داده‌های محلی را حذف نمی‌کند.
- **بدون سرور شخصی:** Gemini به‌صورت مستقیم از اندروید قابل استفاده است؛ فقط یک‌بار کلید رایگان Google AI Studio را در «تنظیمات» وارد کن. کلید روی گوشی با Android Keystore رمزگذاری می‌شود.
- سرور HTTPS قبلی همچنان برای استفاده تیمی اختیاری است و زیر بخش توسعه‌دهنده پنهان شده است.
- ضبط شناور قرمز، نمایش متن اولیه در کادر اصلی و پردازش فقط با دکمه «پردازش با هوش مصنوعی».
- تحلیل فایل صوتی اصلی با Gemini برای کمک به تشخیص گفتار در محیط شلوغ و تشخیص اصلاحات نام/شماره؛ تشخیص صدای ضعیف تضمین‌شده نیست.
- دستورهای مجاز شامل اصلاح نام/شماره/مجموعه، چند شماره، سمت و گروه، یادداشت، ثبت/اصلاح قرار و حذف با تأیید است.
- موارد مبهم مثل «ساعت ۳» بدون تاریخ، پنجره انتخاب روز/ساعت نشان می‌دهند.
- UI مختصر با تنظیمات جدا، گروه‌های قابل‌افزودن، بخش‌های بازشونده و لیست قرارهای آینده.
- فعال‌سازی مستقیم نیازمند API key متعلق به خود کاربر است. هیچ کلیدی در فایل APK قرار داده نشده است.
- [راهنمای راه‌اندازی رایگان و حریم خصوصی](server/README.md)

## نسخه آزمایشی 0.18.2 (در حال ارزیابی روی گوشی)

- کادر مستقل نام، شماره اصلی و شماره‌های اضافی، سمت و دسته‌بندی فعالیت
- فیلتر مجزای گروه و سمت، همراه تشخیص سمت/مجموعه از گفتار
- اتصال اختیاری Agent کم‌هزینه برای تحلیل متن، در صورت تنظیم سرور HTTPS و توکن اختصاصی
- شماره‌گیر اصلی گوشی **هیچ‌وقت توسط پویارا جایگزین نمی‌شود**. فقط هنگام تماس با شماره موجود در CRM اعلان اطلاعات کاری نمایش داده می‌شود و با لمس آن کارت مخصوص مشتری باز می‌شود؛ پاسخ/رد همچنان در تماس عادی گوشی است.
- Agent متنی اختیاری با API پولی OpenAI و مدل پیش‌فرض `gpt-6-luna`؛ تبدیل گفتار زنده همچنان از سرویس SpeechRecognizer اندروید استفاده می‌کند.
- پل اختیاری Google Contacts برای همگام‌سازی مخاطبین علامت‌دار پویارا در حساب انتخاب‌شده؛
  فایل‌های صوتی و عکس‌ها از این طریق منتقل نمی‌شوند
- در نصب تازه و پایگاه داده خالی، گزینه یک‌باره «بازیابی اطلاعات قبلی» در صفحه ثبت سریع دیده می‌شود؛ دکمه‌های ZIP در مخاطبین حذف شده‌اند.
- نسخه‌های آزمایشی با امضای موقتی ساخته می‌شوند؛ ممکن است نصب مستقیم روی نسخه قبلی ممکن نباشد. پیش از حذف نسخه قدیمی خروجی ZIP بگیرید و پس از نصب تازه بازیابی کنید.
- [جزئیات معماری و مراحل راه‌اندازی و تست](docs/poyara-018-architecture-fa.md)

## موقعیت و نقشه آفلاین

- برای هر مخاطب، **GPS فعلی** یا **لمس روی نقشه** ثبت می‌شود. نام شرکت یکسان، موقعیت را به افراد همان شرکت که هنوز موقعیت ندارند منتقل می‌کند.
- در فهرست مخاطبان، «نقشه مشتریان و افراد اطراف من» همه پین‌های ثبت‌شده را نمایش می‌دهد؛ پین‌ها کوچک ولی قابل لمس‌اند و با لمسشان پرونده باز می‌شود.
- دکمه «اطراف من» با مجوز اختیاری موقعیت، افراد در شعاع ۵۰۰ متر، ۲ کیلومتر یا ۵ کیلومتر را پیدا می‌کند. برچسب‌های مبلمان/کابینت/معماری/پیگیری هم فیلتر دارند.
- GPS نیاز به اینترنت نقشه ندارد؛ اما روشن‌بودن خدمات مکان‌یابی گوشی لازم است. موقعیت گوشی تنها هنگام فشردن دکمه خوانده می‌شود، نه پیوسته در پس‌زمینه.
- **برای دیدن خیابان‌ها در حالت آفلاین، یک‌بار باید فایل نقشه Mapsforge با پسوند `.map` مربوط به منطقه را از دکمه «نقشه آفلاین» وارد کنید.** فایل در حافظه خصوصی اپ ذخیره می‌شود و پس از آن هیچ درخواست اینترنتی برای نقشه لازم نیست. بدون فایل، مختصات و پین‌ها کار می‌کنند ولی زمینه خیابان‌ها نمایش داده نمی‌شود.
- داده‌های OpenStreetMap مشمول [شرایط انتساب و ODbL](https://www.openstreetmap.org/copyright) هستند.

## نصب

از [GitHub Actions](https://github.com/MaxLightner/poyara-crm/actions) آخرین بیلد موفق `Android debug APK` را باز کنید و ZIP بخش Artifacts را دانلود کنید. APK داخل ZIP است.

## فعال‌سازی تماس

در صفحه «ثبت سریع»، گزینه «فعال‌سازی شناسایی تماس» را بزنید و مجوز اعلان و نقش Caller ID را تأیید کنید. رفتار اعلان‌ها با مدل گوشی، نسخه اندروید و تنظیمات اعلان متفاوت است؛ نمایش روی صفحه تماس پیش‌فرض تضمین نمی‌شود. اندروید ممکن است شماره‌هایی را که در مخاطبین معمولی ذخیره شده‌اند، بدون مجوز Contacts برای Call Screening ارسال نکند. این نسخه مجوز خواندن مخاطبین را درخواست نمی‌کند.

**پیامک:** پویارا پیامک را خودش ارسال یا دریافت نمی‌کند، فقط متن را به برنامه پیامک پیش‌فرض می‌دهد. ثبت «انتقال به برنامه پیامک» به معنی ارسال موفق یا تحویل نیست. برای صندوق ورودی کامل SMS باید یک برنامه پیش‌فرض پیامک با مسئولیت‌ها و مجوزهای مربوط ساخته شود.

## داده و امنیت

مخاطبین معمولی گوشی خوانده یا تغییر داده نمی‌شوند. داده‌های CRM در حافظه خصوصی اپ هستند. خروجی ZIP رمزگذاری مستقل ندارد؛ آن را در محل امن نگه دارید و قبل از حذف برنامه نسخه پشتیبان بگیرید.

## برنامه آینده

پردازش هوشمند متن و صوت در پس‌زمینه، تفکیک نام/شرکت/سمت با AI، تشخیص مطمئن شرکت‌ها، اتوماسیون پیگیری، همگام‌سازی امن و اتصال مجاز پیام‌رسان‌ها. این موارد هنوز پیاده‌سازی نشده‌اند.
